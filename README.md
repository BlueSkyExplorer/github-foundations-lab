
# GitHub Foundations Lab

A Python project for learning Git and GitHub.

## Features

- Greeting function
- Automated unit tests
- GitHub collaboration workflow

## Tech Stack

- Python 3.12
- pytest
- GitHub Actions

## Installation

```bash
git clone https://github.com/USERNAME/github-foundations-lab.git
cd github-foundations-lab
python -m pip install -r requirements.txt
```

## Usage

```bash
python app.py
```

## Testing

```bash
python -m pytest
```
